# UniCloud Docker Setup Guide

This guide explains how to use the modular Docker Compose setup for UniCloud development, testing, and production.

## Quick Start

### 1. Environment Setup
```bash
# Copy environment template
cp .env.template .env

# Edit .env file with your actual values
nano .env
```

### 2. Development Environment
```bash
# Start development environment
docker-compose -f docker-compose.yml -f docker-compose.dev.yml up -d

# View logs
docker-compose -f docker-compose.yml -f docker-compose.dev.yml logs -f

# Access services:
# - Backend API: http://localhost:8080
# - Database Admin: http://localhost:8081 (Adminer)
# - Redis Admin: http://localhost:8082
# - Debug Port: localhost:5005
```

### 3. Production Environment
```bash
# Start production environment
docker-compose -f docker-compose.yml -f docker-compose.prod.yml up -d

# Monitor services
docker-compose -f docker-compose.yml -f docker-compose.prod.yml ps

# View production logs
docker-compose -f docker-compose.yml -f docker-compose.prod.yml logs backend
```

### 4. Testing Environment
```bash
# Run tests
docker-compose -f docker-compose.yml -f docker-compose.test.yml up --abort-on-container-exit

# Run integration tests only
docker-compose -f docker-compose.yml -f docker-compose.test.yml --profile integration-tests up

# Run performance tests
docker-compose -f docker-compose.yml -f docker-compose.test.yml --profile performance-tests up
```

## File Structure

```
├── docker-compose.yml              # Base configuration
├── docker-compose.dev.yml          # Development overrides
├── docker-compose.prod.yml         # Production overrides
├── docker-compose.test.yml         # Testing configuration
├── Dockerfile                      # Main application Dockerfile
├── Dockerfile.dev                  # Development Dockerfile
├── Dockerfile.test                 # Testing Dockerfile
├── .env.template                   # Environment variables template
├── .env                           # Your actual environment variables (git-ignored)
├── nginx/                         # Nginx configuration for production
├── sql/                          # Database initialization scripts
└── test/                         # Test-related files
```

## Environment Configurations

### Development Features
- **Hot Reload**: Source code changes trigger automatic restart
- **Debug Port**: Remote debugging on port 5005
- **Database Tools**: Adminer for database management
- **Redis Tools**: Redis Commander for Redis management
- **Mock OAuth**: Simplified OAuth for development
- **Detailed Logging**: DEBUG level logging enabled

### Production Features
- **SSL/TLS**: HTTPS encryption via Nginx
- **Resource Limits**: Memory and CPU constraints
- **Health Checks**: Automated service health monitoring
- **Log Aggregation**: Centralized logging with Filebeat
- **Performance Tuning**: Optimized JVM and database settings
- **Security**: Production OAuth credentials and secrets

### Testing Features
- **Isolated Environment**: Separate test database and Redis
- **Mock Services**: Mock OAuth providers for testing
- **Parallel Testing**: Multi-threaded test execution
- **Performance Testing**: Load testing with K6
- **Test Data**: Automated test data generation

## Common Commands

### Development
```bash
# Start development environment
make dev-up
# or
docker-compose -f docker-compose.yml -f docker-compose.dev.yml up -d

# Stop development environment
make dev-down
# or
docker-compose -f docker-compose.yml -f docker-compose.dev.yml down

# View development logs
make dev-logs
# or
docker-compose -f docker-compose.yml -f docker-compose.dev.yml logs -f backend

# Restart backend only
docker-compose -f docker-compose.yml -f docker-compose.dev.yml restart backend

# Execute commands in running container
docker-compose -f docker-compose.yml -f docker-compose.dev.yml exec backend bash
```

### Production
```bash
# Deploy to production
make prod-deploy
# or
docker-compose -f docker-compose.yml -f docker-compose.prod.yml up -d

# Update production application
docker-compose -f docker-compose.yml -f docker-compose.prod.yml pull backend
docker-compose -f docker-compose.yml -f docker-compose.prod.yml up -d backend

# Scale backend instances
docker-compose -f docker-compose.yml -f docker-compose.prod.yml up -d --scale backend=3

# Production health check
make prod-health
# or
curl -f http://localhost:8080/actuator/health
```

### Testing
```bash
# Run all tests
make test
# or
docker-compose -f docker-compose.yml -f docker-compose.test.yml up --abort-on-container-exit

# Run unit tests only
docker-compose -f docker-compose.yml -f docker-compose.test.yml run --rm backend mvn test

# Run integration tests
make test-integration
# or
docker-compose -f docker-compose.yml -f docker-compose.test.yml --profile integration-tests up

# Generate test data
docker-compose -f docker-compose.yml -f docker-compose.test.yml --profile data-generation up test-data-generator
```

## Database Management

### Development Database
```bash
# Access database via Adminer: http://localhost:8081
# Or connect directly:
docker-compose -f docker-compose.yml -f docker-compose.dev.yml exec postgres psql -U dev_user -d unicloud_dev

# Reset development database
docker-compose -f docker-compose.yml -f docker-compose.dev.yml down -v
docker-compose -f docker-compose.yml -f docker-compose.dev.yml up -d postgres
```

### Production Database
```bash
# Backup production database
docker-compose -f docker-compose.yml -f docker-compose.prod.yml exec postgres pg_dump -U $PROD_DB_USER unicloud_prod > backup.sql

# Restore production database
docker-compose -f docker-compose.yml -f docker-compose.prod.yml exec -T postgres psql -U $PROD_DB_USER unicloud_prod < backup.sql

# Monitor database performance
docker-compose -f docker-compose.yml -f docker-compose.prod.yml exec postgres psql -U $PROD_DB_USER -d unicloud_prod -c "SELECT * FROM pg_stat_activity;"
```

## Troubleshooting

### Common Issues

#### Container Fails to Start
```bash
# Check container status
docker-compose ps

# Check container logs
docker-compose logs [service-name]

# Check resource usage
docker stats

# Inspect container configuration
docker inspect [container-name]
```

#### Database Connection Issues
```bash
# Test database connectivity
docker-compose exec backend nc -zv postgres 5432

# Check database logs
docker-compose logs postgres

# Verify environment variables
docker-compose exec backend env | grep SPRING_DATASOURCE
```

#### OAuth Authentication Issues
```bash
# Verify OAuth configuration
docker-compose exec backend env | grep OAUTH
docker-compose exec backend env | grep GOOGLE
docker-compose exec backend env | grep MICROSOFT

# Test OAuth endpoints
curl http://localhost:8080/oauth2/authorization/google
```

#### Performance Issues
```bash
# Check resource usage
docker stats

# Monitor database performance
docker-compose exec postgres pg_stat_activity

# Check application metrics
curl http://localhost:8080/actuator/metrics/jvm.memory.used
```

## Security Best Practices

### Environment Variables
- Never commit `.env` files to version control
- Use strong, unique passwords for all services
- Rotate secrets regularly
- Use different credentials for each environment

### Production Security
```bash
# Ensure SSL certificates are valid
openssl x509 -in /path/to/cert.pem -text -noout

# Check for security vulnerabilities
docker scan unicloud-backend:latest

# Update base images regularly
docker-compose pull
docker-compose build --no-cache
```

### Network Security
```bash
# Audit exposed ports
docker-compose ps
nmap -p- localhost

# Check firewall rules
sudo ufw status

# Monitor network traffic
docker-compose exec backend netstat -tulpn
```

## Backup and Recovery

### Automated Backups
```bash
# Setup automated database backups
crontab -e
# Add: 0 2 * * * /path/to/backup-script.sh

# Backup script example
#!/bin/bash
BACKUP_DIR="/backups/$(date +%Y-%m-%d)"
mkdir -p $BACKUP_DIR
docker-compose exec postgres pg_dump -U $PROD_DB_USER unicloud_prod > $BACKUP_DIR/database.sql
docker-compose exec redis redis-cli --rdb $BACKUP_DIR/redis.rdb
```

### Disaster Recovery
```bash
# Full system restore
# 1. Restore volumes
docker volume create unicloud-prod-postgres-data
docker run --rm -v $BACKUP_DIR:/backup -v unicloud-prod-postgres-data:/data alpine cp -r /backup/postgres /data/

# 2. Restore database
docker-compose -f docker-compose.yml -f docker-compose.prod.yml up -d postgres
docker-compose exec -T postgres psql -U $PROD_DB_USER unicloud_prod < $BACKUP_DIR/database.sql

# 3. Restore Redis
docker-compose -f docker-compose.yml -f docker-compose.prod.yml up -d redis
docker cp $BACKUP_DIR/redis.rdb $(docker-compose ps -q redis):/data/dump.rdb
docker-compose restart redis
```

## Performance Tuning

### Database Optimization
```sql
-- Monitor slow queries
SELECT query, mean_time, calls 
FROM pg_stat_statements 
ORDER BY mean_time DESC 
LIMIT 10;

-- Check database size
SELECT pg_size_pretty(pg_database_size('unicloud_prod'));

-- Analyze table statistics
ANALYZE;
VACUUM;
```

### Application Optimization
```bash
# JVM tuning
JAVA_OPTS="-Xms1g -Xmx2g -XX:+UseG1GC -XX:MaxGCPauseMillis=200"

# Connection pool tuning
SPRING_DATASOURCE_HIKARI_MAXIMUM_POOL_SIZE=20
SPRING_DATASOURCE_HIKARI_MINIMUM_IDLE=5

# Redis optimization
SPRING_REDIS_LETTUCE_POOL_MAX_ACTIVE=20
SPRING_REDIS_LETTUCE_POOL_MAX_IDLE=10
```

## Makefile Commands

Create a `Makefile` for easier command management:

```makefile
# Development
dev-up:
	docker-compose -f docker-compose.yml -f docker-compose.dev.yml up -d

dev-down:
	docker-compose -f docker-compose.yml -f docker-compose.dev.yml down

dev-logs:
	docker-compose -f docker-compose.yml -f docker-compose.dev.yml logs -f

# Production
prod-deploy:
	docker-compose -f docker-compose.yml -f docker-compose.prod.yml up -d

prod-logs:
	docker-compose -f docker-compose.yml -f docker-compose.prod.yml logs backend

prod-health:
	curl -f http://localhost:8080/actuator/health

# Testing
test:
	docker-compose -f docker-compose.yml -f docker-compose.test.yml up --abort-on-container-exit

test-integration:
	docker-compose -f docker-compose.yml -f docker-compose.test.yml --profile integration-tests up

# Maintenance
clean:
	docker-compose down -v
	docker system prune -af
	docker volume prune -f

backup:
	./scripts/backup.sh

restore:
	./scripts/restore.sh
```
